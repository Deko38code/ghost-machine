Mockminer — a Bitcoin mining operations dashboard demo
======================================================
What's on this page:
  * animated rolling hashrate chart
  * Antminer S19 Pro SVG with spinning fans / blinking LEDs
  * miner farm health (3 units)
  * fake wallet generator: Base58Check-style address + WIF private key + demo QR
  * real-time power/efficiency/fan/temp dials
  * block found banner every ~2 min

What's NOT here:
  * real mining, real pool connection, real BTC, real wallet keys

Built on box ghost-Inspiron-7348, port 8213
